- 基准：`random` 固定为 0；其余为相对 ELO。
- 时间控制：每手 `100 ms`；每对局数：`10`；随机开局手数：`2`。
- 种子：20261126；A值：+1。
- MCTS-NN 模型：models/shuyi_resnet_v1.bin。
- 置信区间：对局 bootstrap 95%；对局数有限，区间不可省略。
