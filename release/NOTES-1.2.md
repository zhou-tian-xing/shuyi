只发布界面：引擎与 1.1 相同，包同样不含权重。模型在发布页单独下载。

**1.2 新增**

- **分析随棋谱保存**。存盘时每个局面的数字一起写进去（`#node` / `#cell` / `#cand` 三种行，路径
  而不是节点编号），载入时回到对应局面：棋盘标记、选点、走势、每手颜色立刻可用，不用重算。
  这三种行都以 `#` 开头，1.1 打开带分析的棋谱看到的是同一局棋，只是没有数字。
  文件结构见 [docs/RECORD_FORMAT.zh-CN.md](https://github.com/zhou-tian-xing/shuyi/blob/main/docs/RECORD_FORMAT.zh-CN.md)。
- **Ctrl+S 保存棋谱**（菜单里写着这个键）。
- **文件菜单**：新局 / 保存棋谱 / 载入棋谱 / 退出。左上角那排按钮去掉了，棋盘上方不再有东西。
- **棋盘标记右上角的上标是要落的棋子数字**：同一格能下九个数字，只写“42%”没说该下哪个。
- **棋谱每行左边一小块颜色**：这一手比上一步的评估好了多少。明显更好是蓝色（引擎当时没算过这一手，
  结果超出了它对局面的判断），不差是绿，差是红。不是整行底色，选中这一行时也在。
- **AI 评估那一行改成“分析量 · 速度”**（`4.2k 次 · 1.6k/秒 · GPU`），不再写模型名——模型是用户
  自己选的，复述它没有信息量。
- **走势图画整盘棋**：开头到当前点，再沿主干画到终局；只在当前点的分叉处另画一支虚线变着；目差
  右侧有刻度（`+4 / +2 / -2 / -4`），胜率不标数字、用上下两条淡线标出 0–100% 的带子。
- **棋子剩余数**：下方每格的右上角是小数字（`9³` = 还有三颗 9，`9⁰` 已用完）。

**1.2 改了行为**

- **翻棋谱、载入棋谱不再让电脑自动落子**。以前退一手之后轮到引擎，它立刻应一手，那一手长在棋谱
  中间成了变着，后面的每一手都挂在变着下面——看起来就是“第 50 行以后全成了分支”。现在电脑只在
  三种情况下落子：新开一局它执先、人类落子之后、以及 **引擎 → 让电脑走一步**。轮到它时面板写
  “轮到电脑”。
- **分析是模式**：落子或翻棋谱，落到哪个局面就在哪个局面接着算，不用再按空格；到过访问上限的
  暂停也算“开着”。往后的搜索树会被继承（`play` 带着子树），上翻则重放、数字从头开始。
- **覆盖规则按一次搜索划分**：同一次搜索里数字只增不减，小的快照丢掉；两次搜索之间的数字不可比，
  新的直接覆盖。以前拿旧的大数字压住新结果，面板会停在 14,000 次访问，而引擎实际只算了 300 次。
- **终局不再盖大标题**：棋盘上是空的。左侧第一行是灰色的“终局”，下面写谁胜和最终分值，胜率条
  整条是赢家的颜色。终局局面按规则有精确值，所以最后一手也有颜色，折线落在结果上。

**包**

- `ui-cpu` / `ui-cuda`：界面 + 对应引擎；`engine-cpu` / `engine-cuda`：只有引擎。
- CUDA 包需要 CUDA 12 运行时（`cudart64_12.dll`、`cublas64_12.dll`、`cublasLt64_12.dll`），
  CPU 包不需要任何额外组件。
- 权重不在包里：把 `b<blocks>c<channels>-s<steps>-d<data>.bin` 放进 `models/` 即可。
