界面重做，引擎瘦身。四个包都不含权重，模型单独发布。

**界面**

- 左侧只剩分析的产物：行棋方、胜率与目差、红黑胜率条、AI 评估、选点、当前分值、这条线的走势折线。
- 右侧是棋谱树：↑/↓ 回溯（↓ 走主干），点节点跳过去，Delete 删掉一手和它后面的走法。每个局面
  的分析都缓存在树上，回到旧枝还是原来的数字。
- 菜单从八项减到四项（模式 / 规则 / 引擎 / 帮助）；标题、模式切换、快捷键提示块、点一下就分析的
  误触全部删掉。新局 / 保存 / 载入在左上角，棋谱存成文本（每手 `a4-2`），`shuyi.exe --open x.syp`
  可以直接打开。
- 已解算的着法排在所有估计之前，并标“解”——证明过的东西不该被一个采样压住。

**引擎**

- 删掉 α-β 引擎，只剩 `random` / `mcts` / `mcts_nn`。
- 终盘求解现在有墙钟上限：6 手前整盘解出，7 手给 400 ms 试一次，证明每手 100 ms。以前只有节点
  预算，而同样 7 手的局面在 15k～1.8M 节点之间（14 ms～2.5 s），节点数管不住等待。

**包**

- `ui-cpu` / `ui-cuda`：界面 + 对应引擎；`engine-cpu` / `engine-cuda`：只有引擎。
- CUDA 包需要 CUDA 12 运行时（`cudart64_12.dll`、`cublas64_12.dll`、`cublasLt64_12.dll`），
  CPU 包不需要任何额外组件。
- 权重在资产里单独下载，放进 `models/` 即可。
